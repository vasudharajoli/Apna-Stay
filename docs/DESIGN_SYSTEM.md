# Demo design system

Use warm ivory `#FAF8F5` for the page, navy `#14263D` for body copy, dark terracotta `#A43F2B` for active links and buttons, and warm sand `#F0E6DA` on informative surfaces. Use teal `#246965` to outline keyboard focus.

Pair a Georgia serif heading with system sans-serif controls and body copy. The brand mark combines a roof and sun. Content shares a 1200px maximum width. Property cards use four, two, or one column as available space decreases. Forms use labeled native date inputs and selects, and their primary actions target a minimum height of 44px.

Use a single h1 per page, landmark navigation, a skip link, descriptive image alt text where needed, and announcements for validation or simulation feedback. Keep the demo disclosure visible throughout the guest flow. [Asset provenance](ASSETS.md) documents where media comes from.
